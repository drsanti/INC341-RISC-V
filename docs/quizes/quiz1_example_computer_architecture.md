## ส่วนที่ 1: แนวข้อสอบ (30 ข้อ)

### หมวดที่ 1: Introduction to Computer (ข้อ 1 - 4)

#### 1. ข้อใดคือองค์ประกอบหลัก 3 ส่วนที่ผู้ใช้งาน (User) จะเกี่ยวข้องหรือนึกถึงเมื่อพูดถึงระบบคอมพิวเตอร์ทั่วไป?

- ก. แรม, ซีพียู, และเมนบอร์ด
- ข. ฮาร์ดแวร์, ซอฟต์แวร์, และผู้ใช้งาน (User)
- ค. ระบบปฏิบัติการ, โปรแกรมประยุกต์, และฮาร์ดดิสก์
- ง. คีย์บอร์ด, เมาส์, และจอแสดงผล

#### 2. ข้อใดอธิบายบทบาทและข้อแตกต่างในการเก็บข้อมูลระหว่าง RAM และฮาร์ดดิสก์ (HDD/SSD) ได้ถูกต้องตามบทเรียน?

- ก. RAM ใช้เป็นกระดาษทดเพื่อเก็บข้อมูลชั่วคราวขณะ CPU ทำงาน ส่วนฮาร์ดดิสก์ใช้เก็บข้อมูลถาวร
- ข. RAM ใช้เก็บข้อมูลถาวร ส่วนฮาร์ดดิสก์ใช้เก็บตัวแปรที่กำลังคำนวณชั่วคราว
- ค. RAM มีความเร็วในการอ่านและเขียนข้อมูลช้ากว่าฮาร์ดดิสก์ แต่รักษาข้อมูลไว้ได้แม้ไฟดับ
- ง. RAM เก็บชุดคำสั่งทั้งหมดแบบถาวร ส่วนฮาร์ดดิสก์จะถูกล้างค่าทุกครั้งเมื่อปิดเครื่อง

#### 3. ในมุมมองของวิศวกรหรือนักพัฒนาโปรแกรม นิยามระบบคอมพิวเตอร์ในระดับขั้นต่ำที่สุดประกอบด้วยส่วนประกอบใดบ้าง?

- ก. เมนบอร์ด + การ์ดจอ + แหล่งจ่ายไฟ
- ข. ระบบปฏิบัติการ + โปรแกรมประยุกต์ + ฮาร์ดแวร์
- ค. CPU + หน่วยความจำ (Memory) + อุปกรณ์ต่อพ่วง (Peripherals)
- ง. จอภาพ + คีย์บอร์ด + เมาส์

#### 4. อุปกรณ์ต่อพ่วงชนิดใดต่อไปนี้ที่มักนิยมนำมาต่อเชื่อมเพื่อใช้งานคู่กับเมาส์ในกลุ่มผู้ทำงานด้านสายศิลปะหรืองานออกแบบ (Graphic Design)?

- ก. ปรินเตอร์ (Printer)
- ข. เราเตอร์อินเทอร์เน็ต (Router)
- ค. แผ่นวาดภาพอิเล็กทรอนิกส์ (Tablet/Pad)
- ง. ตัวถอดรหัสตำแหน่ง (Address Decoder)

### หมวดที่ 2: Computer Architecture (ข้อ 5 - 9)

#### 5. หน่วยประมวลผลกลาง (CPU) ในทางสถาปัตยกรรมประกอบด้วยหน่วยการทำงานหลักสองหน่วยใดรวมกัน?

- ก. ALU + Register
- ข. Memory + I/O
- ค. ALU + CU (Control Unit)
- ง. Cache + CU (Control Unit)

#### 6. "หน่วยความจำข้อมูลที่มีลักษณะการทำงานเปรียบเสมือน Whiteboard หรือกระดาษทดที่เขียนแล้วลบออกเขียนใหม่ได้ซ้ำๆ แต่ข้อมูลจะสูญหายทันทีเมื่อไม่มีไฟเลี้ยง" คำอธิบายนี้หมายถึงอะไร?

- ก. ROM (Read Only Memory)
- ข. RAM (Random Access Memory) / Data Memory
- ค. Program Memory
- ง. Hard Disk Drive (HDD)

#### 7. ข้อใดคือคุณสมบัติหลักของ "หน่วยความจำโปรแกรม" หรือ Program Memory (ROM) ตามหลักสถาปัตยกรรมคอมพิวเตอร์?

- ก. ใช้เก็บค่าตัวแปรชั่วคราวขณะคำนวณทางคณิตศาสตร์ ข้อมูลสูญหายเมื่อไฟดับ
- ข. ใช้เก็บชุดคำสั่งภาษาเครื่อง (Machine Code) ตลอดไปแม้ไม่มีไฟเลี้ยง จนกว่าจะถูกเขียนทับใหม่ด้วยกระบวนการพิเศษ
- ค. เชื่อมต่อใกล้ชิดกับ ALU ที่สุด และมีความเร็วสูงกว่า Register เสมอ
- ง. ทำหน้าที่เป็นบัสระบบคอยรับส่งข้อมูลระหว่างอุปกรณ์ภายนอก

#### 8. ข้อใดอธิบายโครงสร้างและลักษณะของสถาปัตยกรรมแบบ Von Neumann (วอน นอยมันน์) ได้ถูกต้อง?

- ก. รวม Data Memory และ Program Memory ไว้ในกล่องเดียวกัน โดยใช้ระบบบัสข้อมูลและบัสตำแหน่งร่วมกันเป็นชุดเดียว
- ข. แยก Data Memory และ Program Memory ออกจากกันอย่างเด็ดขาด และมีระบบบัสแยกกันโดยสมบูรณ์
- ค. CPU สามารถอ่านชุดคำสั่งใน ROM และอ่านเขียนข้อมูลใน RAM ได้พร้อมกันในวินาทีเดียวกัน
- ง. มีความยืดหยุ่นน้อยกว่าสถาปัตยกรรมอื่นเนื่องจากห้ามบันทึกตัวแปรลงใน RAM ร่วมกับคำสั่ง

#### 9. ข้อเปรียบเทียบที่สำคัญที่สุดระหว่างสถาปัตยกรรมแบบ Harvard และ Von Neumann คือเรื่องใด?

- ก. แบบ Harvard มีการออกแบบระบบบัสที่ง่ายกว่าและใช้สายสัญญาณจำนวนน้อยกว่า
- ข. แบบ Harvard แยกชุดบัสของข้อมูลและบัสตำแหน่งออกจากกันอย่างอิสระ ทำให้ CPU อ่านคำสั่งและรับส่งตัวแปรได้ในเวลาเดียวกัน ส่งผลให้ทำงานเร็วกว่า
- ค. แบบ Von Neumann มีความเร็วในการส่งผ่านข้อมูลสูงกว่าเพราะรันบนระบบปฏิบัติการพิเศษ
- ง. แบบ Harvard ไม่อนุญาตให้เขียนข้อมูลลงในหน่วยความจำชั่วคราวได้เลย

### หมวดที่ 3: System Buses (ข้อ 10 - 14)

#### 10. บัสระบบ (System Bus) ในคอมพิวเตอร์แบ่งออกเป็น 3 ประเภทหลักตามลักษณะของสัญญาณ ข้อใดถูกต้อง?

- ก. Input Bus, Output Bus, Control Bus
- ข. Address Bus, Data Bus, Control Bus
- ค. Power Bus, Instruction Bus, Peripheral Bus
- ง. Memory Bus, CPU Bus, Device Bus

#### 11. ทิศทางการไหลของข้อมูลบนบัสข้อมูล (Data Bus) ที่เชื่อมต่อระหว่าง CPU และหน่วยความจำ ROM (Program Memory) มีลักษณะอย่างไรในสภาวะปกติ?

- ก. ไหลได้ 2 ทิศทาง ทั้งอ่านและเขียนอย่างอิสระ
- ข. ไหลออกจาก CPU ไปบันทึกในหน่วยความจำ ROM เท่านั้น
- ค. ไหลจากหน่วยความจำ ROM เข้าสู่ CPU ทิศทางเดียว (Read-Only)
- ง. ไม่มีข้อมูลไหลผ่าน เนื่องจาก ROM จะควบคุมผ่านทาง Address Bus อย่างเดียว

#### 12. เหตุผลสำคัญที่สุดที่สถาปัตยกรรมระบบบัสจำเป็นต้องใช้งานวงจร "ตัวถอดรหัสตำแหน่ง" (Address Decoder) คืออะไร?

- ก. เพื่อช่วยเร่งความเร็วในการคำนวณฟังก์ชันทางคณิตศาสตร์ของ ALU
- ข. เพื่อการันตีว่าจะไม่มีข้อมูลชนกัน (Data Collision) บนบัสข้อมูล โดยกำหนดให้อุปกรณ์/หน่วยความจำเพียงตัวเดียวที่ถูกเปิดการทำงาน ณ จังหวะนั้นๆ
- ค. เพื่อแปลงสัญญาณข้อมูลฐานสิบห้าให้เป็นฐานสิบหก
- ง. เพื่อทำหน้าที่ระบายความร้อนจากชิป CPU ไปสู่บอร์ด

#### 13. ขาสัญญาณใดในระบบบัสควบคุม (Control Bus) ของ RAM ที่จะรับสัญญาณเป็น Logic 0 (Active Low) เมื่อ CPU ต้องการดำเนินการเขียนข้อมูล (Write Operation) ลงใน RAM?

- ก. ขา Read (RD) และขา Chip Enable (CE)
- ข. ขา Write (WR) และขา Chip Enable (CE)
- ค. ขา Read (RD) และขา Write (WR) พร้อมกัน
- ง. ขา Address a15 และ Data d0

#### 14. เมื่อ CPU ดำเนินการขั้นตอนการอ่านคำสั่ง (Instruction Fetch) จากหน่วยความจำ ROM ลำดับสัญญาณใดจะเกิดขึ้นก่อนเป็นอันดับแรก?

- ก. CPU กำหนดตำแหน่งแอดเดรสของคำสั่งที่ต้องการผ่าน Address Bus
- ข. CPU ส่งสัญญาณ Logic 0 ผ่านทางขา Read (RD) เพื่อดึงข้อมูลออก
- ค. ข้อมูลคำสั่งไหลจาก ROM ออกสู่ Data Bus ไปยัง CPU
- ง. CPU ปรับขนาด Data Bus ให้เป็น High Impedance

### หมวดที่ 4: Data and Memory (ข้อ 15 - 18)

#### 15. ในการเขียนโปรแกรมและการจัดการข้อมูลทางดิจิทัล ระบบตัวเลข (Number System) ใดต่อไปนี้ที่ "ไม่นิยมใช้งาน" หรือไม่ได้นำมาใช้ประโยน์ในการระบุตัวแปรตามบทเรียน?

- ก. ระบบเลขฐานสอง (Binary Number System)
- ข. ระบบเลขฐานแปด (Octal Number System)
- ค. ระบบเลขฐานสิบ (Decimal Number System)
- ง. ระบบเลขฐานสิบหก (Hexadecimal Number System)

#### 16. ถ้าหากมีระบบข้อมูลขนาด n บิต (n Bits) ความหลากหลายสูงสุดในการสร้างจำนวนค่าที่แตกต่างกันจะมีค่าเท่ากับเท่าใด?

- ก. n ยกกำลัง 2 ($n^2$)
- ข. 2 คูณ n ($2n$)
- ค. 2 ยกกำลัง n ($2^n$)
- ง. n ยกกำลัง n ($n^n$)

#### 17. ความสัมพันธ์เชิงโครงสร้างในด้านขนาดข้อมูลระหว่าง "บิต (Bit)" และ "ไบต์ (Byte)" อธิบายได้ว่าอย่างไร?

- ก. ข้อมูลขนาด 1 บิตประกอบด้วย 8 ไบต์เรียงต่อกัน
- ข. ข้อมูลขนาด 1 ไบต์ประกอบขึ้นจากกล่องข้อมูลขนาด 1 บิตจำนวน 8 ตัวเรียงต่อกัน
- ค. บิตและไบต์เป็นหน่วยที่มีขนาดเท่ากันเสมอ ขึ้นอยู่กับสเปกของเมนบอร์ด
- ง. 1 ไบต์มีขนาดคงที่เท่ากับ 32 บิตในระบบ 32-bit MCU

#### 18. บิตขวาสุด (ที่มีค่านัยสำคัญต่ำสุด) และบิตซ้ายสุด (ที่มีค่านัยสำคัญสูงสุด) ของชุดข้อมูลขนาด 1 ไบต์ มีคำย่อเรียกว่าอย่างไรตามลำดับ?

- ก. MSB และ LSB
- ข. LSB และ MSB
- ค. CS และ CE
- ง. RD และ WR

### หมวดที่ 5: Address Decoder (ข้อ 19 - 22)

#### 19. ในวงจรตัวถอดรหัสตำแหน่ง (Address Decoder) ชนิด 2-to-4 lines ที่มีขาเปิดการทำงาน (Enable - EN) เป็นแบบ Active Low หากขา EN ได้รับสัญญาณ Logic 1 (High) จะส่งผลต่อเอาต์พุต y0 - y3 อย่างไร?

- ก. เอาต์พุตทุกตัวจะกลายเป็น Logic 1 (ไม่มีอุปกรณ์ใดถูกเลือกให้ทำงานเลย)
- ข. เอาต์พุตทุกตัวจะกลายเป็น Logic 0 เพื่อเลือกใช้งานทุกส่วนพร้อมกัน
- ค. เอาต์พุตจะเปลี่ยนไปตามตารางความจริงขึ้นกับสัญญาณอินพุต A และ B
- ง. เกิดภาวะ High Impedance บน Address Bus

#### 20. จากแบบจำลองการเชื่อมต่อในเลกเชอร์ ขาอินพุต A และ B ของ Address Decoder ต่อพ่วงกับขาสัญญาณ Address บิตที่ 14 และ 15 (a14, a15) ของ CPU หากผู้พัฒนาต้องการเลือกใช้งานอุปกรณ์ I/O ซึ่งต่ออยู่กับเอาต์พุต y2 ค่าของคู่สัญญาณ (a15, a14) ของ CPU จะต้องมี Logic เป็นเท่าใด?

- ก. a15 = 0, a14 = 0
- ข. a15 = 0, a14 = 1
- ค. a15 = 1, a14 = 0
- ง. a15 = 1, a14 = 1

#### 21. จากเงื่อนไขในข้อ 20 พื้นที่แอดเดรส (Address Space) ช่วงต่ำสุด (Min Address) ที่เริ่มต้นในการสั่งงานพอร์ตอุปกรณ์ I/O บนขา y2 จะตรงกับค่า Address 16 บิตในระบบเลขฐานสิบหกข้อใด?

- ก. 0x0000
- ข. 0x4000
- ค. 0x8000
- ง. 0xC000

#### 22. หากต้องการออกแบบให้ระบบคอมพิวเตอร์ดังกล่าวรองรับการจัดกลุ่มหน่วยความจำและพอร์ตอุปกรณ์ต่างๆ เพิ่มเติมจากเดิม 4 กลุ่ม เป็น 8 กลุ่ม จะต้องปรับปรุงฮาร์ดแวร์ของ Address Decoder อย่างไร?

- ก. ขยายบัสข้อมูล (Data Bus) จาก 8 บิตเป็น 16 บิต
- ข. เพิ่มขาอินพุตควบคุมของตัวถอดรหัสตำแหน่งจากเดิม 2 บิตเป็น 3 บิต (เช่น นำ a13, a14, a15 มาต่อเป็นอินพุต)
- ค. ต่อพ่วงขา Chip Enable ไปยังบัสคุมตัวอื่นเพื่อส่งค่าแบบขนาน
- ง. เพิ่มตัวต้านทานดึงกระแสพูลอัป (Pull-up Resistor) ให้ครบทุกบิต

### หมวดที่ 6: CPU Families & ISA (ข้อ 23 - 26)

#### 23. ข้อใดสามารถจำแนกความแตกต่างและคุณลักษณะหลักในการทำงานระหว่าง CPU และไมโครคอนโทรลเลอร์ (MCU) ได้ถูกต้องที่สุด?

- ก. CPU ออกแบบมาเพื่อรันระบบปฏิบัติการทั่วไป (เช่น Windows) ประมวลผลซับซ้อนสูง และต้องต่อหน่วยความจำภายนอก ส่วน MCU รวมแรม/รอม/พอร์ต I/O ไว้ในชิปเดียว ออกแบบมาสำหรับงานควบคุมเฉพาะทาง
- ข. CPU ทำหน้าที่ประมวลผลคำสั่งแบบเวลาจริง (Real-Time) มีขนาดเล็กและราคาถูกกว่า MCU มาก
- ค. MCU ต้องการแรมและฮาร์ดดิสก์จากภายนอกมาต่อเพิ่มจึงจะรันคำสั่งได้ ในขณะที่ CPU สามารถรันคำสั่งได้ทันทีที่จ่ายไฟเลี้ยงโดยไม่ต้องมีอุปกรณ์อื่น
- ง. CPU มักเป็นหน่วยประมวลผลหลักแบบ Single-core ส่วน MCU ในปัจจุบันมีสถาปัตยกรรมแบบ 10+ cores และ Cache L3 ในตัวเสมอ

#### 24. สถาปัตยกรรมชุดคำสั่ง (ISA) แบบ CISC (Complex Instruction Set Computer) และ RISC (Reduced Instruction Set Computer) มักจับคู่กับการใช้งานหลักในตระกูล CPU ใดตามลำดับ?

- ก. CISC ใช้งานในตระกูล ARM และ RISC-V ส่วน RISC ใช้งานในตระกูล x86 ของค่าย Intel/AMD
- ข. CISC ใช้งานในตระกูล x86 (Intel/AMD) ส่วน RISC ใช้งานในตระกูล ARM และ RISC-V
- ค. ทั้ง CISC และ RISC ต่างก็ใช้งานในตระกูล RISC-V ร่วมกันเป็นมาตรฐานโมดูลาร์
- ง. CISC ใช้กับงานฝังตัวประหยัดพลังงาน ส่วน RISC ใช้กับการคำนวณประสิทธิภาพสูงบนเครื่องเซิร์ฟเวอร์

#### 25. ข้อใดคือคุณลักษณะเด่นและข้อดีที่สุดที่ทำให้สถาปัตยกรรม RISC-V แตกต่างจากสถาปัตยกรรมชุดคำสั่งลิขสิทธิ์เฉพาะอย่าง ARM?

- ก. RISC-V ได้รับการออกแบบให้มีเฉพาะคำสั่งคำนวณที่ซับซ้อนมากกว่า ARM จึงมีความเร็วเหนือกว่า
- ข. RISC-V เป็นมาตรฐานแบบเปิดเผยรหัสฟรี (Open Source Design) ทำให้ใครก็สามารถนำมาตรฐานนี้ไปศึกษา วิจัย และพัฒนาต่อยอดได้โดยไม่ต้องเสียค่าสิทธิ์ไลเซนส์
- ค. RISC-V ได้รับการสนับสนุนให้รันร่วมกับระบบปฏิบัติการปิดอย่าง macOS ได้ราบรื่นที่สุด
- ง. RISC-V กำหนดให้ต้องใช้การเชื่อมต่อบัสแบบ One-bus System เท่านั้นเพื่อความเรียบง่าย

#### 26. อะไรคือคุณลักษณะด้านความยืดหยุ่นในทางวิศวกรรมที่เรียกว่า "Modularity" ของ RISC-V ISA?

- ก. สามารถรันโค้ดภาษาเครื่อง x86 ได้ทันทีโดยไม่ต้องผ่านกระบวนการแปลงโค้ดใดๆ
- ข. ยอมให้ออกแบบหน่วยประมวลผลโดยเลือกผสมผสานกลุ่มชุดคำสั่ง (Extensions) ตามความจำเป็นของงาน เช่น ชุดคำสั่งคำนวณอย่างง่าย หรือคำนวณทศนิยมประสิทธิภาพสูง
- ค. บังคับให้บอร์ดไมโครคอนโทรลเลอร์ทุกค่ายต้องเชื่อมต่อขาสัญญาณ Address ครบ 64 เส้น
- ง. ผู้ใช้งานสามารถตัดส่วนของ ALU ทิ้งได้ตามต้องการหากโปรแกรมไม่มีงานประมวลผล

### หมวดที่ 7: Embedded System, RISC-V & Assembly (ข้อ 27 - 30)

#### 27. ข้อใดต่อไปนี้ "ไม่ใช่" คุณลักษณะเฉพาะตัว 6 ข้อหลักของระบบฝังตัว (Embedded System) ที่ระบุในเลกเชอร์?

- ก. ทำงานเฉพาะด้านตามฟังก์ชันที่กำหนด (Dedicated Functionality)
- ข. ทำงานในสภาวะจำกัดทรัพยากร ทั้งแรม/รอมและความเร็วซีพียู (Constrained Resources)
- ค. มีปริมาณทรัพยากรหน่วยความจำและหน่วยประมวลผลที่ล้นเหลือและฟุ่มเฟือย (Abundant Resources)
- ง. การทำงานร่วมกันอย่างสมบูรณ์แบบของฮาร์ดแวร์และซอฟต์แวร์เฟิร์มแวร์ (Integration)

#### 28. "Real-Time Operation" ในบริบทของระบบสมองกลฝังตัว หมายความว่าอย่างไรจึงจะถือว่าระบบทำงานได้สมบูรณ์?

- ก. ระบบต้องเชื่อมต่อเข้ากับฐานข้อมูล Cloud ผ่านอินเทอร์เน็ตอยู่ตลอดเวลา
- ข. การคำนวณและการตอบสนองต่อสัญญาณอินพุตจะต้องประมวลผลเสร็จสิ้นเรียบร้อยภายในกรอบเวลา (Time Frame) ที่กำหนดไว้เท่านั้น
- ค. ระบบต้องใช้ซีพียูที่มีความเร็วสัญญาณนาฬิกา (Clock Frequency) สูงเป็นระดับกิกะเฮิรตซ์ (GHz) เท่านั้น
- ง. ระบบต้องทำงานต่อเนื่องกันอย่างน้อย 1 ปีโดยไม่มีการปิดพักเครื่อง

#### 29. อะไรคือข้อเสียและ "ข้อจำกัดสำคัญที่สุด" ของการเขียนโปรแกรมในระดับระดับฮาร์ดแวร์ด้วยภาษาแอสเซมบลี (Assembly Language)?

- ก. ตัวภาษาทำงานเป็นแบบสากล ทำให้มีความเร็วในการคำนวณช้ากว่าภาษาแอสเซมบลีของตระกูลอื่นมาก
- ข. เป็นภาษาเฉพาะเจาะจงกับสถาปัตยกรรม CPU ตระกูลนั้นๆ (CPU-specific) โค้ดที่พัฒนาสำหรับ CPU ตัวหนึ่ง ไม่สามารถนำไปรันบน CPU ตระกูลอื่นได้โดยตรง
- ค. ต้องส่งโปรแกรมผ่านทางสัญญาณ WiFi เท่านั้นจึงจะบันทึกโปรแกรมลงใน Program Memory ได้
- ง. ไม่สามารถทำงานร่วมกับคำสั่งควบคุมหรือจัดการสับเปลี่ยนตัวแปรในระบบได้เลย

#### 30. ส่วนประกอบใดในชุดคำสั่ง (ISA) ของ RISC-V ที่ทำหน้าที่เป็น "หน่วยความจำขนาดเล็กที่มีความเร็วสูงสุดในการทำงาน อยู่ชิดกับตัวประมวลผล CPU" เพื่อใช้ในการพักตัวแปรสำหรับการคำนวณ?

- ก. RAM (Random Access Memory)
- ข. Register
- ค. Flash Memory
- ง. Program Counter (PC)

## ส่วนที่ 2: เฉลยและคำอธิบายอย่างละเอียด

### 1. ตอบ ข. ฮาร์ดแวร์, ซอฟต์แวร์, และผู้ใช้งาน (User)

_คำอธิบายเพิ่มเติม:_ ในฐานะ User ทั่วไป เมื่อมองภาพระบบคอมพิวเตอร์ จะนึกถึงสามสิ่งนี้คือ ใครเป็นผู้ใช้, ตัวอุปกรณ์ฮาร์ดแวร์ภายนอกและภายในเครื่องมีคุณลักษณะอย่างไร และมีการติดตั้งซอฟต์แวร์ (เช่น OS และโปรแกรมประยุกต์) อะไรเพื่อทำงานบ้าง

### 2. ตอบ ก. RAM ใช้เป็นกระดาษทดเพื่อเก็บข้อมูลชั่วคราวขณะ CPU ทำงาน ส่วนฮาร์ดดิสก์ใช้เก็บข้อมูลถาวร

_คำอธิบายเพิ่มเติม:_ RAM หรือ Data Memory เป็นหน่วยความจำที่ CPU ใช้เป็นกระดาษทดเพื่ออ่านเขียนข้อมูลชั่วคราวระหว่างทำงาน โดยข้อมูลจะสูญหายหากไม่มีไฟเลี้ยง ส่วนฮาร์ดดิสก์หรือ SSD ทำหน้าที่เก็บรักษาไฟล์และโปรแกรมไว้อย่างถาวรแม้ปิดเครื่องไปแล้วก็ตาม

### 3. ตอบ ค. CPU + หน่วยความจำ (Memory) + อุปกรณ์ต่อพ่วง (Peripherals)

_คำอธิบายเพิ่มเติม:_ บทเรียนระบุว่า สำหรับมุมมองของนักพัฒนาโปรแกรมหรือวิศวกร การประกอบขึ้นเป็นคอมพิวเตอร์หนึ่งเครื่องในโครงสร้างขั้นพื้นฐานที่สุดประกอบด้วย CPU ร่วมกับหน่วยความจำ และอุปกรณ์อินพุตเอาต์พุตหรือต่อพ่วงต่างๆ

### 4. ตอบ ค. แผ่นวาดภาพอิเล็กทรอนิกส์ (Tablet/Pad)

_คำอธิบายเพิ่มเติม:_ ในกลุ่มผู้ใช้งานเฉพาะด้าน เช่น นักวาดรูปหรืองานออกแบบ จะใช้อุปกรณ์ต่อพ่วงเพิ่มเติมคู่กับเมาส์และคีย์บอร์ด ได้แก่ ตัวแผ่น Pad หรือแผ่นวาดเขียนอิเล็กทรอนิกส์เพื่อช่วยอำนวยความสะดวก

### 5. ตอบ ค. ALU + CU (Control Unit)

_คำอธิบายเพิ่มเติม:_ สถาปัตยกรรมคอมพิวเตอร์ระบุชัดเจนว่า ตัวประมวลผลกลาง หรือ CPU เกิดจากหน่วยคำนวณทางคณิตศาสตร์และตรรกศาสตร์ (ALU) มารวมกับหน่วยควบคุมการทำงาน (CU)

### 6. ตอบ ข. RAM (Random Access Memory) / Data Memory

_คำอธิบายเพิ่มเติม:_ แรมหรือหน่วยความจำข้อมูลเปรียบได้เสมือนไวท์บอร์ดที่ใช้เพื่อทดคำนวณชั่วคราว CPU สามารถแก้ไขค่าไปมาได้อิสระ แต่จะไม่บันทึกข้อมูลทิ้งไว้เมื่อถอดไฟเลี้ยงออก

### 7. ตอบ ข. ใช้เก็บชุดคำสั่งภาษาเครื่อง (Machine Code) ตลอดไปแม้ไม่มีไฟเลี้ยง จนกว่าจะถูกเขียนทับใหม่ด้วยกระบวนการพิเศษ

_คำอธิบายเพิ่มเติม:_ หน่วยความจำโปรแกรม (Program Memory) หรือ ROM จะทำหน้าที่บันทึกโค้ดภาษาเครื่อง (Machine Code) ที่ได้จากการคอมไพล์โปรแกรม โดยข้อเด่นคือข้อความสั่งการนี้จะคงอยู่ในชิปตลอดไปแม้ไม่มีไฟจ่าย จนกว่าจะเปลี่ยนโปรแกรมใหม่ทับลงไป

### 8. ตอบ ก. รวม Data Memory และ Program Memory ไว้ในกล่องเดียวกัน โดยใช้ระบบบัสข้อมูลและบัสตำแหน่งร่วมกันเป็นชุดเดียว

_คำอธิบายเพิ่มเติม:_ สถาปัตยกรรมแบบ Von Neumann (วอน นอยมันน์) จะมองแรมและรอมให้อยู่ในกลุ่มพื้นที่กล่องหน่วยความจำเดียวกัน โดยมีข้อดีในความเรียบง่ายเนื่องจากใช้ชุดระบบบัส (Data Bus & Address Bus) ร่วมกันเป็นหนึ่งเดียว

### 9. ตอบ ข. แบบ Harvard แยกชุดบัสของข้อมูลและบัสตำแหน่งออกจากกันอย่างอิสระ ทำให้ CPU อ่านคำสั่งและรับส่งตัวแปรได้ในเวลาเดียวกัน ส่งผลให้ทำงานเร็วกว่า

_คำอธิบายเพิ่มเติม:_ สถาปัตยกรรมแบบ Harvard แยกพื้นที่ RAM และ ROM ออกจากกัน และมีบัสแยกเด็ดขาด ทำให้อุปกรณ์สามารถทำงานคู่ขนานได้พร้อมกันในจังหวะเวลาเดียวกัน จึงมีประสิทธิภาพในการประมวลผลการคำนวณที่รวดเร็วกว่าแบบ Von Neumann

### 10. ตอบ ข. Address Bus, Data Bus, Control Bus

_คำอธิบายเพิ่มเติม:_ บัสในสถาปัตยกรรมระบบคอมพิวเตอร์และไมโครคอนโทรลเลอร์จำแนกออกเป็น 3 ชนิดหลัก ได้แก่ บัสข้อมูล (Data Bus) บัสตำแหน่ง (Address Bus) และบัสควบคุม (Control Bus)

### 11. ตอบ ค. ไหลจากหน่วยความจำ ROM เข้าสู่ CPU ทิศทางเดียว (Read-Only)

_คำอธิบายเพิ่มเติม:_ ข้อมูลใน Program Memory (ROM) ตามรูปแบบทั่วไป CPU จะดึงออกไปเพื่อเป็นชุดคำสั่ง (Instruction Flow) จึงไหลในทิศทางเดียวจาก ROM เข้าหา CPU เพื่อใช้งาน และไม่สามารถแก้ไขเขียนกลับลงไปตรงๆ ได้

### 12. ตอบ ข. เพื่อการันตีว่าจะไม่มีข้อมูลชนกัน (Data Collision) บนบัสข้อมูล โดยกำหนดให้อุปกรณ์/หน่วยความจำเพียงตัวเดียวที่ถูกเปิดการทำงาน ณ จังหวะนั้นๆ

_คำอธิบายเพิ่มเติม:_ บัสตำแหน่งและบัสข้อมูลถูกต่อร่วมกันไปยัง RAM และ ROM หากไม่มีตัวจำแนกและควบคุมสัญญาณการเปิดปิด ชิปทั้งสองอาจพยายามปล่อย Logic มาชนกันจนเกิดความเสียหายขึ้น ตัวถอดรหัสตำแหน่ง (Address Decoder) จะทำหน้าที่คัดสรรและเปิดให้ใช้งานชิปใดชิปหนึ่งเท่านั้น ณ เวลาหนึ่งๆ

### 13. ตอบ ข. ขา Write (WR) และขา Chip Enable (CE)

_คำอธิบายเพิ่มเติม:_ เมื่อ CPU สั่งการบันทึกข้อมูลลง RAM จะต้องกำหนดแอดเดรส และเปลี่ยนระดับสัญญาณของขาเลือกชิป (CS/CE) และขาควบคุมการเขียน (WR) ให้กลายเป็น Logic 0 (เนื่องจากทำงานแบบ Active Low) เพื่อยอมรับข้อคำสั่งใหม่

### 14. ตอบ ก. CPU กำหนดตำแหน่งแอดเดรสของคำสั่งที่ต้องการผ่าน Address Bus

_คำอธิบายเพิ่มเติม:_ ลำดับกระบวนการสัญญานเมื่อ CPU ต้องการ Fetch คำสั่งคือ 1) CPU จะกำหนดที่อยู่ (Address) ไปยัง Address Bus 2) ทำการเปิดการใช้งาน Chip Enable 3) ส่งสัญญาณผ่านขา Read (RD) และ 4) รับค่าคำสั่งจากบัสข้อมูล

### 15. ตอบ ข. ระบบเลขฐานแปด (Octal Number System)

_คำอธิบายเพิ่มเติม:_ ในระบบงานฝังตัวปัจจุบัน วิศวกรจะเลือกใช้งานระบบเลขฐานสิบ (สำหรับทำความเข้าใจผลลัพธ์) เลขฐานสอง (สำหรับสถานะบิตขาสัญญาณ) และเลขฐานสิบหก (สำหรับระบุ Address และชุดคำสั่ง) โดยระบบเลขฐานแปดไม่ได้รับความนิยมนำมาใช้งานในการเขียนโปรแกรมบทเรียน

### 16. ตอบ ค. 2 ยกกำลัง n ($2^n$)

_คำอธิบายเพิ่มเติม:_ ในทางคณิตศาสตร์ดิจิทัล ข้อมูลจำนวน $n$ บิตจะมีสภาวะความเป็นไปได้ที่หลากหลายทางสถานะสลับกันเป็นสูตรสำเร็จเท่ากับ $2^n$ เช่น ข้อมูล 4 บิตจะได้ความแตกต่างสูงสุดเท่ากับ $2^4 = 16$ สภาวะ

### 17. ตอบ ข. ข้อมูลขนาด 1 ไบต์ประกอบขึ้นจากกล่องข้อมูลขนาด 1 บิตจำนวน 8 ตัวเรียงต่อกัน

_คำอธิบายเพิ่มเติม:_ หน่วยวัดขนาดหน่วยความจำระดับพื้นฐาน "1 ไบต์ (Byte)" ประกอบขึ้นมาจากการรวมตัวกันของบิตสัญญานทางดิจิทัลขนาด 1 บิตจำนวน 8 บิตเข้าด้วยกันเป็น 1 ชุดข้อมูล

### 18. ตอบ ข. LSB และ MSB

_คำอธิบายเพิ่มเติม:_ บิตที่มีความสำคัญต่ำสุดอยู่ตำแหน่งขวาสุดของชุดข้อมูลจะถูกเรียนว่า LSB (Least Significant Bit) ในขณะที่บิตทางซ้ายสุดซึ่งมีนัยสำคัญสูงที่สุดจะเรียกว่า MSB (Most Significant Bit)

### 19. ตอบ ก. เอาต์พุตทุกตัวจะกลายเป็น Logic 1 (ไม่มีอุปกรณ์ใดถูกเลือกให้ทำงานเลย)

_คำอธิบายเพิ่มเติม:_ วงจรถอดรหัสตำแหน่งส่วนใหญ่จะทำงานด้วยขาเปิดใช้งาน (EN) แบบ Active Low นั่นคือหากได้รับอินพุต EN เป็น Logic 1 สัญญาณเอาต์พุตออกทั้งหมด (y0 - y3) จะค้างค่าเป็น 1 เสมอ เพื่อเป็นสถานะไม่สั่งการอุปกรณ์ใดๆ ในระบบบัส

### 20. ตอบ ค. a15 = 1, a14 = 0

_คำอธิบายเพิ่มเติม:_ วงจรเอาต์พุต y2 จะถูกกระตุ้นเปลี่ยนสถานะเป็น Logic 0 ก็ต่อเมื่อค่าอินพุต AB (เทียบเท่ากับขา a15, a14) มีค่าตามตารางดิจิทัลเท่ากับ "10" (เลข 2 ในรหัสไบนารี่)

### 21. ตอบ ค. 0x8000

_คำอธิบายเพิ่มเติม:_ เมื่อขา a15 = 1 และ a14 = 0 และทดลองปรับแต่งให้บิตที่เหลือ (a0 - a13) เป็น Logic 0 ทั้งหมดเพื่อหาแอดเดรสต่ำสุด (Min Address) ค่าที่แปลงเป็นเลขฐานสิบหกจะมีค่าเริ่มต้นเท่ากับ 0x8000

### 22. ตอบ ข. เพิ่มขาอินพุตควบคุมของตัวถอดรหัสตำแหน่งจากเดิม 2 บิตเป็น 3 บิต (เช่น นำ a13, a14, a15 มาต่อเป็นอินพุต)

_คำอธิบายเพิ่มเติม:_ เพื่อให้ระบบมีชุดข้อมูลย่อยจัดสรรมากขึ้น จากเดิม 4 กลุ่ม ($2^2 = 4$) ไปสู่ 8 กลุ่ม จะต้องปรับปรุงให้ตัวถอดรหัสรับพิกัดแอดเดรสมากขึ้นเป็น 3 บิต ($2^3 = 8$) โดยนำแอดเดรสบิต a13 เข้ามาใช้งานร่วมกับ a14 และ a15

### 23. ตอบ ก. CPU ออกแบบมาเพื่อรันระบบปฏิบัติการทั่วไป (เช่น Windows) ประมวลผลซับซ้อนสูง และต้องต่อหน่วยความจำภายนอก ส่วน MCU รวมแรม/รอม/พอร์ต I/O ไว้ในชิปเดียว ออกแบบมาสำหรับงานควบคุมเฉพาะทาง

_คำอธิบายเพิ่มเติม:_ CPU ถือเป็นหน่วยประมวลผลขนาดใหญ่ที่มีความซับซ้อนสูง เน้นงานประมวลผลทั่วไปและต้องพึ่งพาแรม/ฮาร์ดดิสก์จากภายนอก ส่วน MCU ได้รับการรวมหน่วยความจำและอุปกรณ์ต่อพ่วงไว้ในแพ็กเกจเดียวเพื่อออกแบบมาทำหน้าที่ควบคุมระบบฝังตัวเฉพาะด้าน

### 24. ตอบ ข. CISC ใช้งานในตระกูล x86 (Intel/AMD) ส่วน RISC ใช้งานในตระกูล ARM และ RISC-V

_คำอธิบายเพิ่มเติม:_ CPU ในเครื่องคอมพิวเตอร์ทั่วไปของฝั่ง Intel/AMD จะประมวลผลบนฐานชุดคำสั่งที่ซับซ้อนอย่าง CISC ขณะที่ระบบฝังตัวหรือสมาร์ตโฟนซึ่งเน้นความประหยัดพลังงานจะหันมาเลือกใช้สถาปัตยกรรมแบบ RISC อย่างตระกูล ARM และ RISC-V

### 25. ตอบ ข. RISC-V เป็นมาตรฐานแบบเปิดเผยรหัสฟรี (Open Source Design) ทำให้ใครก็สามารถนำมาตรฐานนี้ไปศึกษา วิจัย และพัฒนาต่อยอดได้โดยไม่ต้องเสียค่าสิทธิ์ไลเซนส์

_คำอธิบายเพิ่มเติม:_ ข้อเด่นอันทรงคุณค่าที่สุดของสถาปัตยกรรม RISC-V คือการเป็นเทคโนโลยีแบบ Open Source ที่เป็นมาตรฐานอิสระ เปิดโอกาสให้ชุมชนพัฒนาทั้งฮาร์ดแวร์และซอฟต์แวร์สามารถเข้ามาวิจัยและสร้างชิปควบคุมได้โดยไม่มีปัญหาภาระเรื่องค่าสิทธิ์ไลเซนส์

### 26. ตอบ ก. RISC-V

_คำอธิบายเพิ่มเติม:_ RISC-V ได้รับการออกแบบสถาปัตยกรรมมาเป็นรูปแบบ "Modular" (โมดูลาร์) เอื้อให้ผู้ผลิตสามารถเลือกและสับเปลี่ยนชุดส่วนขยายของอินสตรักชัน (Extensions) ได้หลากหลายตามจุดประสงค์ของงาน โดยยังคงมาตรฐานความง่ายและประหยัดพลังงาน

### 27. ตอบ ค. มีปริมาณทรัพยากรหน่วยความจำและหน่วยประมวลผลที่ล้นเหลือและฟุ่มเฟือย (Abundant Resources)

_คำอธิบายเพิ่มเติม:_ ลักษณะเด่นที่สำคัญของระบบฝังตัวคือ "การมีทรัพยากรที่จำกัด" (Constrained Resources) ทั้งในแง่ความเร็วของตัวซีพียูและขนาดพื้นที่ความจำ RAM/ROM ดังนั้น การระบุว่ามีทรัพยากรล้นเหลือจึงเป็นข้อมูลที่ไม่ถูกต้อง

### 28. ตอบ ข. การคำนวณและการตอบสนองต่อสัญญาณอินพุตจะต้องประมวลผลเสร็จสิ้นเรียบร้อยภายในกรอบเวลา (Time Frame) ที่กำหนดไว้เท่านั้น

_คำอธิบายเพิ่มเติม:_ การทำงานแบบเรียลไทม์ (Real-Time Operation) คือหัวใจหลักของความปลอดภัยในระบบควบคุม โดยมีข้อบังคับว่าโปรแกรมและซีพียูจะต้องคำนวณและผลิตสัญญาณเอาต์พุตเพื่อตอบสนองต่อเงื่อนไขแวดล้อมให้สำเร็จก่อนจะหมดกรอบเวลา (Time Frame) ที่กำหนดไว้

### 29. ตอบ ข. เป็นภาษาเฉพาะเจาะจงกับสถาปัตยกรรม CPU ตระกูลนั้นๆ (CPU-specific) โค้ดที่พัฒนาสำหรับ CPU ตัวหนึ่ง ไม่สามารถนำไปรันบน CPU ตระกูลอื่นได้โดยตรง

_คำอธิบายเพิ่มเติม:_ เนื่องจากภาษาแอสเซมบลีทำงานใกล้ชิดกับโครงสร้างการจัดวาง Register และคำสั่งภายในชิปโดยตรง จึงกลายเป็นข้อจำกัดว่าโปรแกรมที่เขียนขึ้นสำหรับสถาปัตยกรรมหนึ่ง (เช่น RISC-V) จะไม่สามารถรันข้ามระบบไปยัง ARM หรือ x86 ได้ทันที

### 30. ตอบ ข. Register

_คำอธิบายเพิ่มเติม:_ ในระบบหน่วยประมวลผล RISC-V "Register" (เรจิสเตอร์) คือหน่วยความจำชั่วคราวที่มีระดับความเร็วการรับส่งสูงสุด และจัดวางตระเตรียมไว้ในโครงสร้างภายในซีพียูเพื่อรองรับการดึงข้อมูลจาก ALU เข้ามาจัดการคำนวณได้ทันที
